

The console menu
----------------

This package also has the console menu, and starts with it on. Start on the title screen opens
the list of seven modes -- ARCADE, V.S., RANDOM, SURVIVAL, TRAINING, OPTIONS, NETWORK -- the way
the Dreamcast version does, instead of dropping you straight onto the arcade's fixed road. Up and
down move, Start chooses, B leaves.

OPTIONS is the cabinet's thirteen operator settings, the ones from its test menu, changed with
left and right. Nothing restarts; a setting takes effect when the game next reads it, generally
at the start of the next match.

To play the arcade's road instead, turn Console mode off in the port's own menu (Escape).
