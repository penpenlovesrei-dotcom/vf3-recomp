# Fighting Vipers 2, la route console en ARCADE : la meme chose sans le carrousel.
#
# ARCADE ne passe pas par la page des decors -- le carrousel appartient a la ligne V.S. -- donc la suite
# des etats est plus courte d'un aller-retour, et c'est le point : les deux routes ne sont pas la meme
# mesure. Les deux presses :
#
#   1300  Start sur l'ecran titre     -> la liste des modes       (PLAY -> MENU)
#         VF3_CONSOLE_MODE=arcade      -> ARCADE choisi            (MENU -> PLAY)
#   5700  Start dans le combat        -> le menu pause            (PLAY -> PAUSE)
#         VF3_CONSOLE_PAUSE=4          -> MAIN MENU               (PAUSE -> MENU_IN -> MENU)
#
# 5700 n'est pas rond par hasard : en arcade le combat commence vers l'image 5300 (l'ecran de selection
# laisse la machine choisir, ce qui prend son temps), et la presse doit tomber dedans.
#
# La suite attendue : PLAY MENU PLAY PAUSE MENU_IN MENU
1300 press p1.start 8
5700 press p1.start 8
