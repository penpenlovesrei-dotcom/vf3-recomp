# fv2-console-start.txt's path, then a fatal blow forced by VF3_POKE.
#
#   vf3run fvipers2.zip --script tools/scripts/fv2-vic-bench.txt --modes \
#          --console-mode versus --console-at 1960 --frames 3600 --wav sound.wav
#   VF3_POKE=581457=1,70756b=0,70756a=0  VF3_POKE_FRAMES=2600-2604
#
# 581457: side 0's counter of rounds won (0x00581454 ^ 3), pushed to 1 so that the next blow reaches the
#         match point. 70756b/70756a: fighter 1's health (0x00707568), put to zero, so the round ends in
#         a K.O.
